# lolesportkrillion
Krillion-like game for League of Legends esports

## Data and attribution

The default GitHub Actions import uses [GPTilt's LoL Esports Matches dataset](https://huggingface.co/datasets/gptilt/lol-esports-matches), derived from [Leaguepedia](https://lol.fandom.com/wiki/Leaguepedia) contributors, under [CC BY-SA 3.0](https://creativecommons.org/licenses/by-sa/3.0/). The generated question bank is an adaptation distributed under the same license. The snapshot contains teams, picks and tournaments, not individual player picks. Coverage depends on the source. The direct import remains available manually and uses Leaguepedia ScoreboardPlayers. A snapshot will not overwrite an existing non-snapshot bank. See bank.meta.json for the active source when present.
